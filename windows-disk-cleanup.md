# Как освободить место на диске C в Windows: приоритетные шаги

> **Важно:** Папка `%TEMP%` уже очищена. Ниже — дальнейшие действия в порядке убывания эффективности.  
> ⚠️ **Не трогайте:** `C:\Windows\System32`, `C:\Program Files`, `C:\Program Files (x86)`, папки системных драйверов и каталоги лицензионного ПО.

---

## 1. Очистка Корзины

**Что делает:** удаляет файлы, перемещённые в Корзину, — они продолжают занимать место на диске до окончательного удаления.

**Как выполнить:**
- Щёлкните правой кнопкой по иконке «Корзина» на рабочем столе → **Очистить корзину**.
- Либо откройте Корзину, нажмите **Управление → Очистить корзину**.

**Потенциальный выигрыш:** от единиц МБ до нескольких ГБ, если в Корзину давно ничего не удаляли.

---

## 2. Запуск встроенного очистителя диска (cleanmgr)

**Что делает:** удаляет временные файлы Интернета, эскизы, файлы отчётов об ошибках, установочные кэши и многое другое.

**Как выполнить:**
1. Нажмите `Win + R`, введите `cleanmgr`, нажмите Enter.
2. Выберите диск **C:** → ОК.
3. Отметьте всё, что предлагает утилита (временные файлы Интернета, журналы ошибок, корзина и т. д.).
4. Нажмите **ОК → Удалить файлы**.

**Дополнительно (очистка системных файлов):**
- В том же окне нажмите **Очистить системные файлы** (требует прав администратора). Это откроет расширенный список, включающий пакеты обновлений и файлы предыдущих установок Windows.

**Потенциальный выигрыш:** 500 МБ — 5+ ГБ.

---

## 3. Удаление старых обновлений Windows (очистка WinSxS)

**Что делает:** папка `C:\Windows\WinSxS` хранит резервные копии компонентов Windows и старые версии обновлений. После очистки обновления удалить нельзя, но освобождается значительное место.

**Как выполнить (вариант 1 — через cleanmgr):**
- В «Очистке диска» выберите **Очистить системные файлы**.
- Отметьте пункты **Обновления Windows**, **Предыдущие установки Windows**, **Пакеты драйверов устройств** (если есть).

**Как выполнить (вариант 2 — через командную строку):**
1. Откройте командную строку **от имени администратора** (`Win + X → Командная строка (администратор)`).
2. Выполните команду:
   ```
   Dism.exe /online /Cleanup-Image /StartComponentCleanup /ResetBase
   ```
3. Дождитесь завершения (может занять 5–20 минут).

**Потенциальный выигрыш:** 2–15 ГБ в зависимости от истории обновлений.

---

## 4. Очистка папок «Загрузки» и «Документы»

**Что делает:** в папках `%USERPROFILE%\Downloads` и `%USERPROFILE%\Documents` часто скапливаются большие и давно ненужные файлы — ISO-образы, архивы, старые установщики, видео.

**Как выполнить:**
1. Откройте Проводник → «Этот компьютер» → папка «Загрузки».
2. Отсортируйте файлы по **размеру** (вид → Подробности → клик по столбцу «Размер»).
3. Удалите крупные файлы, которые точно не нужны (установщики, видео, старые архивы).
4. Повторите для папки «Документы» и рабочего стола.

**Рекомендуемый инструмент:** встроенный Проводник с сортировкой по размеру.

**Потенциальный выигрыш:** 1–20+ ГБ.

---

## 5. Очистка кэша браузеров

**Что делает:** браузеры сохраняют кэш страниц, изображения, скрипты. Со временем кэш может занять несколько ГБ.

**Google Chrome:**
1. `Ctrl + Shift + Del` → Диапазон «Всё время».
2. Отметьте «Кэшированные изображения и файлы», «Файлы cookie» (если нужно).
3. Нажмите **Удалить данные**.

**Mozilla Firefox:**
1. `Ctrl + Shift + Del` → Диапазон «Всё».
2. Отметьте «Кэш» → Удалить.

**Microsoft Edge:**
1. `Ctrl + Shift + Del` → выберите диапазон → «Кэшированные изображения и файлы» → Очистить.

**Дополнительно — отключение лишних автозагрузочных приложений:**
- `Ctrl + Shift + Esc` (Диспетчер задач) → вкладка **Автозагрузка**.
- Отключите программы, которые вам не нужны при старте системы (они не удаляются, просто перестают запускаться автоматически).

**Потенциальный выигрыш:** 500 МБ — 5 ГБ.

---

## 6. Проверка крупных «забытых» папок

**Что делает:** в некоторых системных и пользовательских папках накапливаются данные старых или давно удалённых программ.

**Папки для проверки:**

| Путь | Что искать |
|------|-----------|
| `%AppData%\Roaming` | Кэши удалённых программ, логи, старые плагины |
| `%AppData%\Local` | Папки `Temp`, кэш Discord, Teams, Slack, старых IDE |
| `%ProgramData%` | Данные деинсталлированных программ |
| `C:\Users\<имя>\AppData\Local\Packages` | Данные приложений из Microsoft Store |
| `C:\Users\<имя>\AppData\Local\Google\Chrome\User Data\Default\Cache` | Кэш Chrome вручную |

**Как найти самые крупные папки:**
1. Нажмите `Win + R` → введите `%AppData%` → Enter.
2. Отсортируйте папки по размеру или воспользуйтесь WinDirStat (см. шаг 7).

**Потенциальный выигрыш:** 1–10 ГБ.

---

## 7. Поиск мусора и дублей через сторонние программы

**Рекомендуемые инструменты:**

### WinDirStat (бесплатно)
- Скачайте с [windirstat.net](https://windirstat.net/).
- Визуально показывает, какие папки и файлы занимают больше всего места.
- Позволяет быстро найти «неожиданно большие» файлы и папки.

### TreeSize Free (бесплатно)
- Аналог WinDirStat с более удобным интерфейсом.
- Скачайте с официального сайта JAM Software.

### CCleaner (осторожно)
- Очищает временные файлы, кэши, реестр.
- ⚠️ Используйте только модуль очистки файлов; от очистки реестра лучше воздержаться — выигрыш минимален, а риск сломать систему есть.

**Для поиска дублирующихся файлов:**
- **dupeGuru** (бесплатно, открытый код) — находит дубликаты по содержимому.
- **AllDup** — простой бесплатный поиск дублей.

**Потенциальный выигрыш:** зависит от ситуации; WinDirStat поможет найти скрытые «пожиратели места».

---

## 8. Удаление неиспользуемых программ

**Что делает:** деинсталляция ненужного ПО освобождает место, занятое исполняемыми файлами, библиотеками и рабочими данными программ.

**Как выполнить:**
1. `Win + R` → `appwiz.cpl` → Enter (или Панель управления → Программы и компоненты).
2. Отсортируйте список по столбцу **Размер**, чтобы видеть самые крупные программы.
3. Выберите ненужную программу → **Удалить**.

**На что обращать внимание:**
- Старые версии Java, Python, .NET, Visual C++ Redistributable (если установлена более новая версия).
- Игры, которые вы больше не играете.
- Пробные версии программ, о которых забыли.
- Предустановленный bloatware (программы производителя ноутбука).

**Потенциальный выигрыш:** 1–30+ ГБ.

## ⛔ Что не трогать

- `C:\Windows\System32` — критически важные системные файлы
- `C:\Program Files` и `C:\Program Files (x86)` — удаляйте только через «Программы и компоненты»
- `C:\Windows\System32\drivers` — драйверы устройств
- Папки лицензионного корпоративного ПО (1C, AutoCAD и т. д.) — только через официальный деинсталлятор
- Файлы с расширениями `.dll`, `.sys`, `.exe` в системных директориях — не удалять вручную
